
# UIProbe

### AI Visual, Accessibility & Autonomous Web Testing Platform

**See. Test. Understand. Improve.**

UIProbe is an intelligent web testing platform designed to identify visual defects, accessibility violations, functional failures, and responsive layout issues in web applications.

## Project Objectives

- Automated browser testing using Playwright.
- Visual defect detection using OpenCV.
- Accessibility auditing using axe-core.
- Functional and responsive testing.
- AI-powered defect explanations.
- Automated test case generation.
- Comprehensive quality reports.

## Technology Stack

| Layer | Technology |
|---|---|
| Frontend | React, TypeScript |
| Backend | Python, FastAPI |
| Browser Automation | Playwright |
| Accessibility | axe-core |
| Computer Vision | OpenCV |
| Machine Learning | Scikit-learn |
| Database | PostgreSQL |
| Task Queue | Redis |
| Infrastructure | Docker |

## Project Structure

- frontend/ - React application
- backend/ - FastAPI application
- worker/ - Browser automation and testing
- ml/ - Machine learning experiments
- docs/ - Technical documentation
- deployment/ - Deployment configuration

Build a reliable AI-assisted testing platform that helps developers identify, understand, and reproduce web application defects.
